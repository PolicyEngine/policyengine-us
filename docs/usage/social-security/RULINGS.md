# Restricted-survivor modeling ruling

For the contributed S.770 section 2 preset, a worker who died before 2026 and
before attaining 62 receives the 95% first factor at the death-based computation
benchmark. The parameter
`recompute_pre2026_death_before_eligibility` controls **only** the 18% increase
to that benchmark's first bend point. False therefore retains the 95% factor;
true applies both changes. Deaths after 2025 are outside this switch.

This is an explicit scenario interpretation, not a statutory conclusion. The
switch defaults false and must be recorded with the scenario. For AIME above
the increased first bend point, the raw monthly gain is .05 * original BP1
with the switch false, or .1634 * original BP1 with it true.

Source: [119th Congress S.770, section 2(a) and (c)](https://www.congress.gov/bill/119th-congress/senate-bill/770/text).
