SNAP, Medicaid, SPM unit benefits and net income compute again for every Indiana and Kansas household from 2027. The Indiana and Kansas state supplements now read Medicaid enrollment before work requirements, which breaks a dependency cycle through the Medicaid community engagement SNAP pass-through without changing any result. Clients that set `is_medicaid_eligible` or `medicaid_enrolled` to switch these supplements on or off should set `medicaid_enrolled_before_work_requirements` instead.
