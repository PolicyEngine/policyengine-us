The marginal tax rates, `marginal_tax_rate_on_capital_gains`, `employer_ss_tax_income_tax_revenue` and `employer_medicare_tax_income_tax_revenue` now remove their temporary branch with `simulation.branches.pop(name, None)`, so they calculate on a simulation that keeps no branch it creates, such as policyengine-core's planned read-only simulations, instead of raising `KeyError`. Calculated in a branch with the name they give their own branch, they now raise `ValueError` before changing that branch's inputs or system.
